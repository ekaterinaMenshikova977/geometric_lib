# Geometric Lib

Geometric Lib - библиотека на языке Python, предназначенная
для вычисления площадей и периметров геометрических фигур

В текущей версии проекта реализованы функции для работы
с кругом и квадратом.

Библиотека содержит два основных файла:
- circle.py - вычисление площади круга и длины окружности
- square.py - вычисление площади и периметра квадрата


# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a


## Описание функций
### circle.py

Файл содержит функции для вычисления площади круга и длины окружности

#### Функция area(r)

**Параметры**
r (int или float) - радиус круга

**Возвращаемые значения**
math.pi * r * r (float) - площадь круга 

**Пример вызова**
area(3) -> 28.274333882308138

#### Функция perimeter(r)

**Параметры**
r (int или float) - радиус круга

**Возвращаемые значения**
2 * math.pi * r (float) - длина окружности 

**Пример вызова**
perimeter(5) -> 31.41592653589793

### square.py

Файл содержит функции для вычисления площади и периметра квадрата

#### Функция area(a)

**Параметры**

a (float или int) - длина стороны квадрата

**Возвращаемые значения**

a * a (float или int) - площадь квадрата

**Пример вызова**

area(6) -> 36

#### Функция perimeter(a)

**Параметры**

a (float или int) - длина стороны квадрата

**Возвращаемые значения**

4 * a (float или int) - периметр квадрата

**Пример вызова**

perimeter(6) -> 24

## Модульное тестирование

Для проверки корректности работы библиотеки geometric_lib
используется стандартный модуль Python `unittest`.

### Тестируемые модули

- `circle.py` — вычисление площади и длины окружности.
- `square.py` — вычисление площади и периметра квадрата.

### Реализованные тест

Для каждого модуля разработаны четыре теста:

1. Проверка площади при нулевом значении параметра.
2. Проверка площади при положительном значении параметра.
3. Проверка периметра при нулевом значении параметра.
4. Проверка периметра при положительном значении параметра.

Всего реализовано 8 модульных тестов.

### Запуск тестирования

Для запуска всех тестов необходимо выполнить команду:

```bash
python3 -m unittest discover -v
```
